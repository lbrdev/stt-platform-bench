# stt-platform-bench

Замер пропускной способности ASR-модели Omnilingual CTC 1B (int8, ONNX)
на разных архитектурах CPU.

Отвечает на один вопрос: **сколько часов аудио одно ядро обрабатывает за час.**

Аудио синтетическое (розовый шум с речеподобной огибающей) — никаких данных,
только нагрузка на энкодер. Модель тянется с Hugging Face.

Запуск: Actions → STT platform benchmark → Run workflow.
Результат: артефакты `bench-x86_64` и `bench-arm64` с `result.json`.
